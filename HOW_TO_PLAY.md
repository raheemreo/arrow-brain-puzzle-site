# 🏹 Arrow Brain Puzzle — Complete How to Play Guide

Welcome to **Arrow Brain Puzzle** — a minimalist, relaxing, and mentally stimulating puzzle game where spatial logic, pathfinding, and foresight come together.

> **Core Objective**: *Fill the entire board with a single continuous line, moving from the Start cell to the Exit cell, visiting every valid arrow cell exactly once.*

## 1. 🎯 The Core Rules

```
 🟢 [Start]  ──▶  [Arrow]  ──▶  [Arrow]
                                   │
                                   ▼
 🏁 [Exit]   ◀──  [Arrow]  ◀──  [Arrow]
```

To solve any puzzle in **Arrow Brain Puzzle**, you must obey 4 fundamental rules:

1. **Start at the Green Cell (🟢)**: Your path always begins at the designated starting point.
2. **Visit Every Cell (100% Fill)**: You cannot skip any valid tile. Every single arrow cell on the grid must be part of your solution path.
3. **No Retracing or Crossing**: You can visit each cell **only once**. Moving back over an already visited tile is forbidden.
4. **Finish at the Exit Cell (🏁)**: The very last cell of your path must be the designated Exit tile.
5. **Orthogonal Movement Only**: You can only move to directly adjacent horizontal or vertical neighbors (Up, Down, Left, Right). **No diagonal moves** are permitted.

## 2. 🎮 Controls & Interaction

| Control Action | Gesture | Description |
| :--- | :--- | :--- |
| **Continuous Path Draw** | **Swipe / Drag** | Press down on the start cell (or the current endpoint) and drag your finger across adjacent tiles to draw a continuous flow. |
| **Single-Step Move** | **Tap** | Tap any valid adjacent unvisited neighbor cell to extend the path by one step. |
| **Undo Last Step** | **Tap ↶ Undo Button** | Reverts your previous move, retracting the path by one cell without resetting your entire progress. |
| **Restart Puzzle** | **Tap ↺ Restart Button** | Resets the current board back to the initial start position with 0 moves drawn. |
| **Request a Hint** | **Tap 💡 Hint Button** | Opens the Hint dialog to reveal the next guaranteed correct cell on the board. |

## 3. 🧩 Board Elements & Visual Guide

```
┌──────┬──────┬──────┐
│  🟢  │  ➡️  │  ⬇️  │   🟢 = Start Cell (Path Origin)
├──────┼──────┼──────┤
│  ⬆️  │  ⬛  │  ⬇️  │   ⬛ = Obstacle / Inactive Cell (Cannot enter)
├──────┼──────┼──────┤
│  🏁  │  ⬅️  │  ⬅️  │   🏁 = Exit Cell (Final Destination)
└──────┴──────┴──────┘
```

- **🟢 Start Cell**: Marked with a glowing emerald origin marker. Always the starting point of the path.
- **➡️ Arrow Indicators**: Guide the flow orientation across the board.
- **⬛ Grid Obstacles / Voids**: Irregular shapes or blocked tiles that cannot be entered.
- **🏁 Exit Tile**: The target finish point. Marked with a checkered flag or goal icon.
- **✨ Radiant Trail**: Your active line path that glows as you drag across the board (customizable in the Shop).

## 6. 💡 Hints & Recovery System

If you get stuck or run into a dead end with no legal adjacent moves remaining, the game offers several assistance systems:

### A. Coin Hint (Instant)
- **Cost**: 30 🪙 Coins per hint.
- **Allowance**: **3 coin hints per cycle**.
- **Cooldown**: After using 3 coin hints, a **5-minute cooldown** starts before your 3/3 allowance recharges.
- **Effect**: Instantly highlights the exact next step of the optimal solution.

### B. Rewarded Video Hint (Free)
- **Cost**: Free (Watch a short sponsor video).
- **Daily Cap**: **5 Rewarded Hints per calendar day**.
- **Progressive Cooldown System**:
  - Hint #1 $\rightarrow$ 3-Minute Cooldown (`03:00`)
  - Hint #2 $\rightarrow$ 5-Minute Cooldown (`05:00`)
  - Hint #3 $\rightarrow$ 10-Minute Cooldown (`10:00`)
  - Hint #4 $\rightarrow$ 30-Minute Cooldown (`30:00`)
  - Hint #5 $\rightarrow$ Daily Limit Reached (Resets tomorrow)

### C. Automatic Stuck Recovery
If your current path leaves unvisited adjacent cells inaccessible, the **Stuck Modal** will appear offering options to **Undo**, **Use Hint**, or **Restart**.

## 10. 🧠 Master Strategies & Pro Tips

### 1. Identify "Forced" Corner Cells First
If a corner cell has only **one way in and one way out**, your path *must* enter and exit through those specific neighbors. Identify these early before drawing long loops.

### 2. Work Backwards from the Exit (🏁)
Look at the Exit tile. How many adjacent cells connect to it? Knowing which tile must immediately precede the Exit allows you to avoid accidentally stepping onto that predecessor too early.

### 3. Avoid Creating "Islands" (Isolated Cells)
When drawing a line through the center of the grid, make sure you don't cut off a group of unvisited cells so they have no remaining entry/exit points. Always ensure that the remaining open cells form a single connected shape.

### 4. Use Undo (↶) Over Full Restarts (↺)
When you realize you've made a mistake, tap **Undo** 2 or 3 times to back out of the trap rather than resetting the entire board. This saves time and keeps you on track for a 3-star rating!
